Ten-fold aggregates for Gaussian PCG, D-weighted PCG, warm-start adaptive B BayesA MCMC, GLMA Gaussian and GLMA prior-selected. Pending or failed aggregates have no score. Fold dots describe variation across the saved folds.

GLMA retains its existing variance and prior-selection workflow. Its variance setup column records the initial stage; later grid work stays within fitting time.
These aggregate results use retained private development interfaces to the existing native engines. Individual predictions and implementation source stay private; [build identities](../assets/reports/training-variance/build-info.csv?v=802595498d46594d), [machine context](../assets/reports/training-variance/machine-info.csv?v=802595498d46594d) and [process measurements](../assets/reports/training-variance/process-resources.csv?v=802595498d46594d) identify the evaluated runs.
